## Notes d'interprétation

- Les **NB indiqués** sont les valeurs après APE (cibles post-travaux définies dans l'offre finale DALKIA)
- La **référence avant travaux** (colonne "Référence GLOBALE GAZ+ELEC") est différente et représente la baseline
- Les sites avec **NB = 0** pour le gaz n'ont soit pas de chauffage gaz, soit sont déjà sur réseau de chaleur ou électrique
- Les colonnes **ECS** indiquent m³/an de référence (m dans la formule NC)
- **qECS** est défini site par site dans le bordereau de prix ; la plupart des sites résidentiels ont qECS implicitement calculé
